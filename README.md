# 场景图与语音交互实验

基于 Flask 的场景图交互原型，结合语音输入、文本解析与场景查询。仓库保留原名称 `seacherAgent`。

| 入口 | 内容 |
|---|---|
| `app.py` | Web 服务，包含语音、文本处理、查询与场景接口 |
| `scene_graph.py` | 场景图与解析逻辑 |
| `templates/index.html` | 页面入口 |

属于早期实验，运行依赖包括 Flask、FunASR 及相应模型/服务配置；本次未重建环境或验证运行。不要将录音、真实服务凭证或个人运行文件加入后续提交。
